Design system — gold version (primary)

Alef Capital Color Palette

The same gold-and-navy identity as the first version, this time with computed contrast figures and a six-color chart palette that passes color-blindness validation in both light and dark mode.

1. Primary ramp — gold

400 is the brand color and the base for buttons. For text, use only 700 and darker — the lighter steps do not have enough contrast on white.

The main trap in this palette: gold text on white. #C9861A only reaches 3.04:1 — it fails for normal body text. Wherever you want gold text, use #8A5A08 (5.92:1) or #6B4506 (8.47:1).

Rule: green and red are for market data only — never for a button or a brand element. And color must never be the only carrier of meaning: put a ▲ or ▼ marker next to every percentage.
Warning specific to this palette: the warning orange (#D97706) sits very close to the brand gold. Signal a warning with an icon and text, not with color alone.

4. Chart palette PASS in both modes

The order is fixed and is never cycled: the first series is always gold, the second always blue. Color attaches to the entity, not to the rank — a filter that changes the number of series must not recolor the ones that remain.

Light mode — on white

Worst adjacent pair ΔE 16.8 (deuteranopia) · normal-vision floor ΔE 18.8 · all contrasts above 3:1

Gold #B4790F Blue #2E5FE0 Orange #D9482B Teal #0E9CAD Purple #9333EA Magenta #B0197A

Dark mode — on #0B1220

Independent steps, not an automatic inversion. Worst pair ΔE 9.2 · normal-vision floor ΔE 15.8

Gold #B8862A Blue #5B8DF5 Orange #EC5F3A Teal #159FAD Purple #A970E8 Magenta #DE4E93
Sequential ramp (bubble intensity): monochrome gold from light to dark — #FEF0CC → #FDE29B → #F0B429 → #C9861A → #8A5A08. Never a rainbow.
Diverging ramp (negative/positive bubble): #0F7233 ← gray #E2E8F0 → #B91C1C — the midpoint is always a neutral gray, never a third hue.
From the seventh series onward: do not invent a new color. Group into "other", or break the chart into small multiples.
